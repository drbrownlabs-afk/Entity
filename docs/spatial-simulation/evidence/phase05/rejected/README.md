# Transferencia rechazada por calidad

El operador rechazó expresamente la primera transferencia PlayCanvas: «parece un juguete» y «no a sacrificio de la calidad».

La captura `lounge-flat-transfer.png` es evidencia de un fallo, no un resultado aceptado. La comparación usa la cámara `revision-lounge` del mismo maestro aprobado. Se encontraron omisiones de techos/remates escondidos para la vista general, recolores de Cycles no transferidos, distinto tone mapping y falta de iluminación indirecta/reflejos interiores adecuados.

El pase de rutas, IDs o compresión no compensa estos defectos. Gate visual Fase05 ABIERTO. Los benchmarks en curso se interrumpieron para priorizar esta corrección; no se declara aceptación ni equivalencia visual.
